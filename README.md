# ڕیل — سکرین ڕیکۆردەر

ئەپێکی دێسکتۆپی کوردی بۆ تۆمارکردنی شاشە لە ویندۆز (MP4).

## کردنەوە

```powershell
.\target\release\screen-recorder.exe
```

یان:

```powershell
cargo run --release
```

## بەکارهێنان

1. مۆنیتەر هەڵبژێرە
2. دوگمەی تۆمار داگرە
3. دووبارە داگرە بۆ وەستان
4. فایل لە فۆڵدەری `recordings` پاشەکەوت دەبێت
